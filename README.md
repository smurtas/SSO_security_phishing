# Human Factors in Single Sign-On Phishing Detection

Research project developed within an internship and Master's thesis in Data Science at the University of Trento, in collaboration with the Center for Cybersecurity at Fondazione Bruno Kessler (FBK).

The project investigates human factors in the recognition of phishing attacks involving federated authentication and Single Sign-On (SSO) systems.

## Project overview

The study focuses on:

- phishing in federated authentication environments;
- Single Sign-On based on OAuth 2.0, OpenID Connect and SAML;
- user recognition of legitimate, suspicious and malicious authentication scenarios;
- security awareness and phishing detection behaviour;
- educational intervention and pre/post experimental evaluation;
- statistical analysis of user responses, confidence and decision time.

## Application

The experimental web application is developed with React, TypeScript and Vite.

Main sections include:

- participant information and consent;
- participant questionnaire;
- experiment instructions;
- phishing and legitimate SSO scenarios;
- results;
- educational material.
